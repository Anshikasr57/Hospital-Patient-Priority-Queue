💊 Treat Next Patient

Removes the highest-priority patient and marks them as treated.

Heap Op: extractMax() → swap root with last → pop → heapifyDown() → O(log n)

🔍 Search Patient

✏️ Update Patient Priority

Change a waiting patient's urgency level. Heap will be reorganized.

Heap Op: Find by ID O(n) → update key → heapifyUp() + heapifyDown() → O(log n)

🗑️ Remove Patient

Remove a waiting patient by ID. Heap property is restored after removal.

Heap Op: Find by ID O(n) → swap with last → pop → heapifyUp() + heapifyDown() → O(log n)
